## ⚡ Highlights & Key Features

- **Developer-Centric UX**: Terminal Drawer (`Ctrl+\`` or `/` command), Command Palette (`⌘K`), Interactive Code Diff Viewer.
- **Private Interview Dossier (`/interview`)**:
  - Protected via encrypted session tokens (`SHA-256`) and dynamic terminal authentication gateway (`/interview`).
  - **VS Code IDE Workspace**: Fully interactive left file explorer categorized by Tech Stacks (`01-react-nextjs`, `02-state-data-layer`, `03-performance-virtualization`, `04-engineering-leadership`, `05-mobile-react-native`, `06-backend-bff-node`).
  - **STAR Model Methodology**: In-depth Situation, Task, Action, and Result breakdown with quantified metrics.
  - **Production Artifacts**: 1-click syntax-highlighted code samples and interactive SVG/CSS Mindmap decision trees.
- **Architectural Performance**:
  - Next.js 16 Turbopack build with static optimization.
  - Zero layout shift (CLS = 0) and smooth Lenis scrolling.
  - Dark mode obsidian/zinc palette tailored for engineering recruiters and engineering leaders.

## 🚀 Getting Started

### Prerequisites

- Node.js >= 18.17.0
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/nguyendangtruong79/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

### Build for Production

```bash
npm run build
npm run start
```
